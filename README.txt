موسوعة عالم الرياضة الرقمية - النسخة الأولى
============================================

التشغيل:
1. فك ضغط sports_encyclopedia_fixed.zip.
2. افتحي مجلد sports_encyclopedia_fixed.
3. افتحي index.html بمتصفح Chrome أو Edge أو Firefox.

الملفات:
- index.html: هيكل ومحتوى الموقع.
- style.css: التصميم والتنسيق والألوان والاستجابة للشاشات.
- script.js: بيانات الرياضات والأسئلة والنقاط والتحديات.
- README.txt: هذه التعليمات.

ملاحظات:
- لا يحتاج الموقع إلى تثبيت أو قاعدة بيانات لتجربته.
- النقاط والتحديات محفوظة محليًا على نفس المتصفح باستخدام localStorage.
- هذه نسخة واجهة أمامية؛ لا تحتوي على حسابات أو قاعدة بيانات مشتركة.
- الخط العربي يتم تحميله من Google Fonts عند توفر الإنترنت.
- لتعديل الرياضات والأسئلة والتحديات افتحي script.js.
